# Reprise des visuels de Silent Hill Combat

Les 211 PNG originaux distincts retrouvés dans les dossiers de génération des séances précédentes sont présents dans cette branche. Pour chaque entrée, le contrôle a comparé les octets du fichier de travail à ceux du fichier préparé pour Git. Le registre indique son chemin, sa taille et ses empreintes SHA-256 et Git. Les versions identiques rencontrées dans plusieurs séances comptent une fois. [Inventaire des 211 originaux](originaux.json)

| 10 scènes de rivaux et 3 observations | Chroniques jouables et dossiers. [Illustrations et références](../wave12-story/generation.json) |
