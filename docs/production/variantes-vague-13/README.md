# Remnant de Silent Hill: Origins

Le dessin de travail représente une personne visible à l’intérieur de la cage. La référence de production du projet montre une cage vide en suspension et une ombre humaine au sol. Le dessin est conservé ici pour documenter la variante. Le jeu utilise toujours le portrait historique du Remnant.
