# Chroniques de Silent Hill Combat

Les quinze chroniques disposent chacune d’une ouverture et d’une fin illustrées. Cette vague réunit les sept dernières paires. Le registre conserve la version corrigée de la fin d’Hinako. [Aperçu des sept paires](overview.jpg) · [Journal des illustrations](generation.json)

|---|---|---|
| La brume d’Alessa | Harry à l’accueil de Midwich | Porte de Nowhere |
| La sentence de James | La lettre de Mary à Wood Side | Lac Toluca |
| Le fils qui revient | La maison des Shepherd | La photographie de famille |
| Les gardiens du livre | L’ouvrage ouvert | Les traces sur le livre refermé |
| 204863 | Le couloir en L | La radio silencieuse |
| La procession d’Hinako | Les rues d’Ebisugaoka | Le sanctuaire |
| Les cendres d’Alessa | Midwich | Les cendres dans le sanctuaire |

Deux images supplémentaires apparaissent quand le joueur atteint le combat du rival. Dans **Naître deux fois**, Heather rencontre Memory of Alessa dans la chapelle retenue pour ce chapitre. Dans **Les vingt-et-un sacrements**, Walter Sullivan se retourne dans le couloir d’Apartment World. La rencontre se déclenche sur l’identifiant du combattant dans la chronique, y compris après la reprise d’une progression enregistrée entre deux combats. Le jeu conserve les conditions de victoire et les fins existantes. [Sources et empreintes des deux illustrations](rivals.json)

Le premier passage de vérification des sept paires a couvert les quinze chroniques. [Rapport initial et captures](qa-initial/report.json)

Dans la version compilée, le bouton **Combat suivant** affiche le double après le cinquième combat de Heather. La reprise du parcours de Silent Hill 4 affiche Walter au cinquième combat. Après une défaite, **Réessayer cette rencontre** ramène directement au duel.
