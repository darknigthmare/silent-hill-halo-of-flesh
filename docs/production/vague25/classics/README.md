# Vague 25 — classiques et Downpour

Trois vues latérales natives RGBA distinctes sont prêtes pour import : Larval Stalker (Silent Hill 1999), Tormented Soul et Wall Corpse (Downpour 2012). Ce sont des candidats de référence pour l’atelier, tous hors duel dans les règles actuelles. Aucun nouveau portrait ni clip animé n’est ajouté.

`delivery.json` contient les trois entrées `selected[]`, les chemins natifs, les empreintes, les références et les calibrages provisoires. Les fichiers PNG sont les octets exacts d’imagegen, conservés sans retouche ni conversion. Les cinq références téléchargées correspondent aux SHA historiques.

## Revue

- Larval Stalker : silhouette entière passive tournée vers la droite. Une correction ciblée de matière a remplacé la brume claire du premier résultat par l’ombre sombre translucide de la source. Le premier résultat reste archivé, non sélectionné. La région, la densité alpha et la profondeur latérale ne sont pas mesurées.
- Tormented Soul : cage entière et une seule effigie fixe, ouvertures réellement transparentes. La référence native 300×300 ne permet pas de certifier les détails latéraux cachés. Aucun membre de marche ou rôle de combat ajouté.
- Wall Corpse : torse naturel complet et supports métalliques, profil vers la droite ; aucune jambe, main, cage ou roue ajoutée. Les détails du côté caché restent une reconstruction.

Les marges demandées de 12 % ne sont pas toutes obtenues, mais aucun élément lisible n’est coupé. Les calibrages doivent être vérifiés dans l’atelier avant publication. Fidélité toujours `unverified`, aucune certification 1:1.

## Exclusions documentées

Air Screamer possède déjà quatre images actives dont une vue latérale de déplacement et un idle animé : aucun remplacement fixe n’est produit. Le Stalker armé n’a pas de vue exacte suffisamment établie. Maria finale appartient à la même famille visuelle que le refus Mary consigné après sa génération historique : aucun nouvel essai.

Les prompts exacts des quatre appels, reçus, sorties, contrôles alpha et audit des six profils sont fournis. Le registre, le moteur, les tests existants et git n’ont pas été modifiés par cette livraison.
