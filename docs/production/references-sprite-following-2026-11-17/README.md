# Références conservées — Insane Cancer Arcade

Ces quatre petites références documentent le personnage exact. Elles servent à la revue ; elles ne sont pas chargées comme sprites par le jeu.

- `insane-cancer-arcade-390s-native.png` : carte explicitement nommée **Insane Cancer**, à 6:30 dans la vidéo de metheload.
- `insane-cancer-arcade-400s-native.png` et `insane-cancer-arcade-450s-native.png` : vues continues à 6:40 et 7:30, jambes et pieds entiers.
- `sh_arcade_15.jpg` : capture du jeu The Arcade, plus lisible sur le haut du corps mais pieds coupés.

Les trois vignettes font **120 × 90 px**, sans agrandissement ni détail ajouté. La vidéo présente une conversion `.xab/.x` vers MDL7 ; elle ne constitue pas une certification des octets du modèle original. Les détails fins des pieds, les surfaces arrière et la géométrie exacte restent non certifiés.

Source vidéo : https://www.youtube.com/watch?v=IlbdUgTlD_g ; capture : https://www.silenthillmemories.net/sh_arcade/screens/pics/sh_arcade_15.jpg . Les dimensions et SHA-256 sont dans [provenance.json](provenance.json). Les pixels copiés sont identiques aux références inspectées.
